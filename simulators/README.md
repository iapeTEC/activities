# Codex Lab

Site estático em português que simula a instalação e o primeiro uso do Codex CLI em Windows, macOS e Linux. Nenhum comando digitado é executado no computador.

## Como abrir

Abra `index.html` diretamente no navegador ou, nesta pasta, rode:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

Os comandos de macOS/Linux e o fluxo de início foram baseados na documentação oficial do Codex CLI consultada em agosto de 2026.
